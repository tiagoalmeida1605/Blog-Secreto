## 📖 Sobre o projeto

O **Blog Secreto** nasceu como um projeto para estudar desenvolvimento web e colocar ideias em prática.

A proposta é criar um blog moderno, leve e responsivo, servindo tanto como laboratório de programação quanto como um espaço para publicar conteúdos futuramente.

O projeto está sendo desenvolvido do zero utilizando tecnologias da web, buscando escrever código limpo, organizado e fácil de manter.

---

## 🚀 Objetivos

- Criar um blog moderno
- Aprender HTML, CSS e JavaScript na prática
- Desenvolver uma interface bonita e responsiva
- Organizar o código seguindo boas práticas
- Evoluir o projeto continuamente

## 💻 Como executar

Clone o repositório:

```bash
git clone https://github.com/tiagoalmeida1605/Blog-Secreto.git
```

Entre na pasta:

```bash
cd Blog-Secreto
```

Depois basta abrir o arquivo `index.html` no navegador ou utilizar uma extensão como **Live Server** no VS Code.
